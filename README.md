# 加油站班次交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 交接批次与离线合并

页面已从单条交接记录扩展为**交接批次**：一个班次关联油枪读数、现金与电子支付流水。

- **离线保存**：每个终端（T-01/T-02/T-03）有独立本地库（`localStorage`），断网录入全部留本机待同步；开两个浏览器标签页选不同终端即可模拟两名值班员同时离线录入。
- **合并**：重连后按「终端编号#流水号」幂等合并到模拟远端库，重复同步不会产生重复流水；支付凭证号相同的流水视为同一笔支付，只计一次，其余标记剔除。
- **字段冲突**：字段级三方合并（本地/远端/上次同步基线），同字段双方都改过则保留两版、流水暂不计入合计，由站长逐字段选择版本，绝不按后到覆盖。
- **复核冻结**：站长复核后批次与关联流水只读，新流水自动归入下一批次，上次结算差额标记「已失效·待重算」，重算后恢复有效。
- **失败重试**：写入中断（可勾选模拟）后批次保留为待同步并标记失败，重试只补未完成流水。
- **历史升级**：旧版 `dfwlfront-7-shift` 的两条示例记录自动迁移为历史批次（已复核→已冻结），仍可查看。
- **同步面板**：页面顶部展示各终端最近同步时间、待同步与待处理冲突数量。
